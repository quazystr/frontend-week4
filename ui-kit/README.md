# UI-Kit (Витрина компонентов)

Проект представляет собой статическую витрину UI-компонентов, сверстанную с соблюдением современных стандартов веб-разработки, методологии БЭМ и принципов доступности (a11y).

## 📦 Реализованные блоки

Ниже представлен список реализованных блоков с их элементами и модификаторами в соответствии с методологией БЭМ.

1. **header**  
   Шапка сайта с логотипом и навигацией.  
   _Элементы:_ `header__logo`, `header__nav`
2. **menu**  
   Список навигационных ссылок.  
   _Элементы:_ `menu__item`, `menu__link`
3. **showcase**  
   Базовый раздел витрины для группировки контента.  
   _Элементы:_ `showcase__title`, `showcase__text`
4. **swatch**  
   Образец цвета из палитры.  
   _Элементы:_ `swatch__name`  
   _Модификаторы:_ `swatch--primary`, `swatch--secondary`, `swatch--success`, `swatch--danger`, `swatch--warning`, `swatch--info`, `swatch--light`, `swatch--dark`
5. **button**  
   Интерактивная кнопка.  
   _Модификаторы:_ `button--secondary`, `button--danger`, `button--small` (базовый стиль применяется по умолчанию).  
   _Состояния:_ `:hover`, `:focus-visible`, `:active`, `:disabled`
6. **badge**  
   Статусный ярлык (бейдж). Используется строго с базовым классом.  
   _Модификаторы:_ `badge--success`, `badge--warning`, `badge--danger`
7. **field**  
   Обертка для поля ввода с подписью и подсказкой.  
   _Элементы:_ `field__label`, `field__control`, `field__hint`  
   _Модификаторы:_ `field--error`  
   _Состояния:_ `:disabled` (для вложенного input)
8. **form-list**  
   Контейнер для списка полей формы.
9. **card**  
   Карточка товара или контента.  
   _Элементы:_ `card__image`, `card__title`, `card__text`, `card__link`
10. **card-list**  
    Сетка карточек (адаптивная).
11. **alert**  
    Блок системного уведомления.  
    _Элементы:_ `alert__title`, `alert__text`  
    _Модификаторы:_ `alert--success`, `alert--danger`

## ✅ Результаты проверок

Все требования проверены вручную и с помощью автоматических инструментов:

- **Валидация W3C:** Код успешно проходит проверку на [validator.w3.org](https://validator.w3.org/) **без ошибок** (Errors: 0).
- **Отсутствие дубликатов ID:** Все формы на странице используют уникальные идентификаторы (префиксы `demo-` для витрины и `course-` для формы заявки). Связь `<label for="...">` и `<input id="...">` работает корректно для каждого поля.
- **Адаптивность (360px):** Горизонтальная прокрутка полностью устранена. Использован глобальный `box-sizing: border-box`, корректные адаптивные ширины и `overflow-x: hidden` для `body`.
- **Доступность (a11y):** Навигация клавишей `Tab` проходит все интерактивные элементы. Видимый фокус (`:focus-visible`) четко отображается на всех элементах, **включая поля с классом ошибки `field--error`** (стиль фокуса не перекрывается красной рамкой).
- **Устойчивость контента:** Заголовок карточки на три строки не ломает верстку. Кнопка в карточке прижата к низу благодаря Flexbox (`margin-top: auto`). Карточка без картинки выглядит аккуратно, отступы сохранены, визуальных дыр нет.
- **Глобальные переменные:** При смене значения `--color-primary` в `variables.css` акцентные элементы (кнопки, ссылки, фокус) меняют цвет по всему проекту.

## ⚙️ Технические требования

- **БЭМ:** Все классы написаны строго по методологии БЭМ. Модификаторы используются только вместе с базовым классом блока.
- **Селекторы:** Селекторы по тегам используются только в `base.css` для сброса стилей. Селекторы по ID для стилизации **отсутствуют** (атрибуты `id` используются исключительно для связи `label[for]` с `input[id]` и для якорных ссылок).
- **Inline-стили:** В HTML-разметке полностью отсутствуют атрибуты `style`.
- **CSS-переменные:** Все цвета, отступы и размеры шрифтов вынесены в `variables.css` и используются через функцию `var()`.
